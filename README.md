# 麻将学习器

一个**纯前端、零依赖**的麻将学习网站。你可以和 3 个电脑玩家打一局完整的麻将，同时得到实时的出牌建议、术语讲解和胡牌复盘——适合零基础入门，边打边学。

## 主要功能

- **完整对局**：136 张牌（万、条、筒、风、箭，无花牌），你 vs 3 个 AI，支持摸牌、出牌、吃、碰、明杠／暗杠／加杠、自摸、点炮与流局。
- **出牌建议**：每轮你出牌时，右侧面板给出推荐牌和理由，并列出候选出牌的优劣排序；听牌时显示等待哪些牌、各剩几张。可用开关随时关闭提示。
- **新手名词解释**：牌桌下方有术语关系图和分类速查表，涵盖牌型、向听、听牌、进张、吃碰杠胡、番型等常见名词；可展开／收起。
- **胡牌复盘**：胡牌后拆解面子与将，列出达成的牌型并给出点评。
- **规则说明页**：顶栏「规则」入口，讲清本工具规则，并对比浙江、四川、广东、日本、国标等打法的差异。

## 如何运行

无需安装、无需构建、无需后端。任选一种：

- **直接打开**：双击 `index.html`，即可在浏览器中游玩。
- **本地服务器**（推荐，图片加载更稳定）：在本目录执行
  ```bash
  python -m http.server 8765
  ```
  然后访问 `http://localhost:8765/`。
- **部署上线**：把整个目录上传到任意静态托管（GitHub Pages、Vercel、对象存储等）即可。

## 文件结构

```
index.html    主页：牌桌、操作栏、出牌建议、名词解释、备案信息
regions.html  规则说明页：本工具规则 + 各地打法差异对比
styles.css    全部样式（极简黑白灰 + 朱红点缀，含移动端适配）
mahjong.js    规则引擎：牌墙、胡牌判定、向听数、听牌、进张、番型、吃碰杠胡判定
app.js        对局流程与界面交互：回合调度、AI 出牌、提示与复盘
term-map.svg  新手名词关系图
```

## 规则范围

采用**通用简化规则**：136 张无花牌牌墙，和牌为「4 组面子 + 1 对将」或七对子，不计番、不算分。它不照搬任何单一地区，重点是把各地通用的基本功（牌型组合、听牌、向听、进张、吃碰杠胡）讲清楚。各地特色规则（花牌、财神、缺一门、立直、番种计分等）只在规则页作差异说明，未在游戏中实现。

## 技术说明

- 原生 HTML / CSS / JavaScript，没有任何第三方库或构建步骤。
- 对局状态全部在浏览器内存中计算，不上传任何数据。
- 支持桌面与移动端；手机端布局自动调整为单列、备案信息分三行居中显示。
